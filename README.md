## Google My Maps 手機測試

測試網址：https://iko887288.github.io/startown-preview/poc/mymaps/

請先登入 Google 帳號，再用 iPhone Safari、Android Chrome 與電腦測試景點資訊、Day 1／Day 2 圖層、完整地圖入口及景點路線規劃。實際 App 跳轉依裝置設定而異。測試頁不需要 STarTown 帳號或 API Key。
